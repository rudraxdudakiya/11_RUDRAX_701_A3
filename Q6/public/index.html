Question 6: Free API Utilities

Call any free API for a useful utility from Frontend and Backend.

1. Backend API Call: Live Weather Utility

Browser calls Express backend (/api/weather), which fetches and processes data from the free Open-Meteo API.

2. Frontend API Call: Currency Converter Utility

Browser directly calls the free public ExchangeRate API (https://open.er-api.com/v6/latest/USD).

3. Frontend API Call: Random Joke Utility

Browser directly calls the free public Official Joke API (https://official-joke-api.appspot.com/random_joke).
